# 페르소나 검사 — 회귀 예측·분석 대회 (목차 · 파트 1~6 · 실전 연습장)

검사 기준일: 2026-11-27 · 자기 결과물 평가(비판 우선) · 5점 만점, 0.5 단위
핵심 페르소나: **수학이 너무 어렵고, 행렬·벡터를 처음 공부하는 학생**

## 0. 대상 요약
- 6파트 30챕터 + 실전 연습장. 두 팀(초파리 팀: 시아·X1·X2 / 주판봇 팀: 모아·하루·X3)이 6라운드 회귀 대회를 벌이고 박사가 판정(최종 3 대 3).
- 흐름: 직선(최소제곱·R²) → 다중회귀·결과표(t·p·AIC·VIF) → 잔차분석(LINE 가정·변환·영향점·심슨) → 경사 하강·학습률·과적합·릿지·라쏘 → 나무·숲·부스팅·KNN·SVR·신경망, 샤플리 값·SHAP 대 회귀계수·잔차 → 로지스틱·소프트맥스·포아송·분위수·다층/패널/시계열.
- 모든 챕터에 왜 상자 / 하루의 수식 상자(학교 수학 연결 + 손계산) / 대화 / 실험 / 풀이 / 한계 / 접는 코드 / 퀴즈. 파트마다 쪽지시험 5문항, 숫자는 브라우저가 직접 계산(검산 스크립트 69항목 통과).

## 5. 정리
입문 쪽(A·C)은 "그림과 손계산은 좋지만 한 번에 읽기엔 길고, 행렬이 나오는 두 챕터가 고비"라고 봤고, 실무·전문가 쪽(D·E·F)은 "오류 정정과 한계 표시가 정직하다"는 데 점수를 줬다. 점수 차이가 작은 이유는 어려운 부분마다 하루의 질문 상자와 작은 숫자 예제가 있기 때문이다. 핵심 페르소나에게 가장 효과가 큰 1~4순위(행렬 손계산, p값 정의, 기호 사전, 모바일 수식)는 이미 반영했다. 다음으로는 교사용 차시 안내(5순위)와 표지 교체(9순위)가 비용 대비 효과가 크다.
