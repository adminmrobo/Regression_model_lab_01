# 작업 메모

- 독자 진단: **혼합형으로 가정**(요청: 수학이 너무 어렵고 행렬·벡터를 처음 공부하는 학생, 중학생도 이해). 수식 막힘형 처방을 먼저 — 기호는 하루의 질문 상자에서 하나씩, 모든 수식 앞에 그림·작은 숫자, 행렬은 챕터 6에서 "상수 하나 맞추기 = 평균"과 점 3개 연립방정식으로만.
- 구성: 6파트 30챕터 + 실전 연습장(4사업장·미션 12개). 팀: 초파리 팀(인턴1 시아·X1·X2), 주판봇 팀(인턴2 모아·조수 하루·X3), 심판 박사. 라운드 결과 주판봇–초파리–초파리–주판봇–주판봇–초파리 → 최종 3 대 3.
- 원자료 정정(목차 "바로잡은 곳"에 모음): DataInterview 정규방정식의 ŷ → y, R²/수정 R² 식 뒤바뀜, 2p − 2ln(L) = AIC, 가정 목록 Independence 중복·정규성 누락 / "Stochastic Regression" = SGD로 맞춘 선들 / Insightforge "T5%" 미사용 / Spearman 예제 검산 맞음 / Matt Lee "surey" → surely.
- 데이터: 모두 tools/gen.py의 고정 씨앗으로 만든 교육용 예시. 라운드 데이터는 두 방법의 차이가 잘 보이는 씨앗을 골랐고, 각 대회 규칙 아래에 그 사실을 밝힘.
- 검산: `python3 tools/verify_numbers.py` (statsmodels·scikit-learn 대조) 69항목 통과. 실전 연습장 미션: `python3 tools/test_practice.py`로 정답 조작을 흉내 내 12개 모두 통과 확인. 390·1280px 가로 넘침 0, 콘솔 오류 0 (`python3 tools/check.py`).
- 금지어 전체 검색 0건(독자 비하 별칭, 스킬 용어 규칙의 금지 표현 세 가지).
- 표지: 생성 도구 그림을 받을 수 없어 `tools/make_covers.py`로 400×225 픽셀 배경을 4배 무손실 확대하고 정식 캐릭터 그림을 합성한 **임시 표지**. 고해상도 픽셀아트 지시문은 docs/IMG_PROMPTS.md.
