# 그림 지시문 (생성 도구용)

지금 표지 8장은 이 지시문으로 Genspark에서 받은 정식 그림입니다(2026-11-27 반영). 다시 받으면 `python3 tools/import_covers.py <받은 폴더>`로 크기를 맞추고 `python3 build.py`를 돌리면 됩니다.

## 공통 규칙
- 흰 배경 계열의 밝은 장면, **가로 1600 이상에서 직접 그린, 픽셀이 작고 촘촘한 16비트 RPG 픽셀아트**(얼굴·손·소품이 세밀하게). 큰 네모 블록으로 확대한 그림은 쓰지 않음.
- 캐릭터는 저장소 `assets/chars/`의 정식 그림(박사·초파리·주판봇·시아·모아·하루·X1·X2·X3)을 참고 그림으로 함께 올림. X1·X2·X3는 검은 실루엣(고양이·리본 소녀·안경 소년).
- 글자는 영어 짧은 낱말만(REGRESSION CUP 등). 한국어 글자 넣지 않음.
- 받은 그림: `cover_*.webp` 1600×900(220 KB 이하), `og_*.webp` 1200×630, `thumb_*.webp` 960×420(표지에서 잘라 냄).

## 만드는 순서 (목차 표지를 먼저 받아 그림체 확인 → 나머지에 참고 그림으로)
| 파일 | 장면 |
|---|---|
| cover_index | 운동장 가운데 큰 칠판(점들 + 보라 회귀 직선 + 빨간 잔차 줄, 제목 REGRESSION CUP). 왼쪽 초파리 팀(초파리·시아·X1·X2), 오른쪽 주판봇 팀(주판봇·모아·하루·X3), 가운데 심판석의 박사 |
| cover_part1 | 아이스크림 가게 앞. 칠판에 기온–판매량 점과 직선, 점마다 위아래 짧은 빨간 줄. 박사가 가리키고 초파리·시아가 의심하는 얼굴, 주판봇·모아가 자신만만 |
| cover_part2 | 칠판에 기울어진 평면 격자와 점들, 옆에 coef / std err / t / p 표. X1·X2·X3가 칠판을 올려다보고 하루가 물음표를 띄움 |
| cover_part3 | 칠판에 가운데가 볼록한 빨간 잔차 점들, 커다란 돋보기. 초파리가 지휘봉으로 가리키고 주판봇이 놀람 |
| cover_part4 | 골짜기 비탈을 노란 공이 여러 번 튀며 바닥으로 내려감. 작은 칠판에 내려가는 손실 곡선. 주판봇·하루가 손잡이를 돌리고 초파리가 지켜봄 |
| cover_part5 | 운동장 양옆 픽셀 나무들, 칠판에 물결 곡선과 계단 선, 붕어빵 노점에서 X1·X2·X3가 돈을 나누는 작은 장면 |
| cover_part6 | 칠판에 초록 S자 곡선, 점점 높아지는 막대, 부채꼴로 퍼지는 세 선(10%·50%·90%). 두 팀이 함께 웃고 박사가 3 : 3 점수판을 듦 |
| cover_practice | 연구실 조종실, 벽 화면 네 개(ICE·RENT·GD·PASS). 하루가 손잡이 앞, 박사·시아·모아·초파리·주판봇이 지켜봄 |
